Sou estudante do primeiro semestre de Sistemas de Informação na UniDoctum e já estudava desenvolvimento web antes de iniciar a graduação.

Atuo como desenvolvedor e web designer freelancer. Gosto de conectar código e design para criar interfaces claras, responsivas e agradáveis de utilizar.

Nos meus estudos, venho explorando JavaScript, PHP e a integração entre interface, servidor e banco de dados. Os laboratórios registram esse percurso por meio de projetos que posso testar, revisar e ampliar.

Busco uma oportunidade de estágio para colaborar com uma equipe, aprofundar meus conhecimentos e participar do desenvolvimento de aplicações reais.
